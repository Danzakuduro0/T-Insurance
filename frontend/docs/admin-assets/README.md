# Ресурсы администратора и выбора роли

Источник: [Figma · Т-Страхование](https://www.figma.com/design/s6nhRji3xk5E3It2m9SskY/), экраны 19–22 (`8:223`–`8:226`).

SVG сохранены без изменения исходных данных и размеров корневого элемента. Для Android/iOS/Web используются PNG в `shared/src/commonMain/composeResources/drawable`.

| Ресурс | Слой / размер в макете | Применение |
|---|---|---|
| `admin_chart` | Icon/chart · 24 × 24 | «Обзор», слот 20 dp |
| `admin_team` | Icon/team · 24 × 24 | «Команда», слот 20 dp |
| `admin_settings` | Icon/settings · 24 × 24 | «Правила», слот 20 dp |
| `admin_alert` | `20:686` · 24 × 24 | Предупреждение о нагрузке |
| `admin_workload_chart` | `20:715` · 728 × 160 | График из макета с сохранением пропорций |
| `admin_demo_user` | `20:1159` · 40 × 40 | Выбор клиента |
| `admin_demo_headset` | `20:1165` · 40 × 40 | Выбор оператора |
| `admin_demo_settings` | `20:1170` · 40 × 40 | Выбор администратора |

PNG экспортированы с тройной плотностью. Иконки выбора роли экспортированы из конкретных экземпляров 40 × 40, чтобы сохранить толщину штриха при изменённом размере компонента. Исходные SVG `admin_user.svg` и `admin_headset.svg` оставлены для справки.

Колокольчик, поиск, очередь, документ, отметки чекбоксов и значок информации используют существующие `operator_*`: их исходные SVG совпадают с ресурсами соответствующих слоёв Figma. Шрифт Inter, цвета, карточки, кнопки и поля взяты из общей темы приложения.

График — статический учебный пример из макета. Полные изображения экранов не используются в интерфейсе. Временных ссылок на Figma в коде нет.
