# Ресурсы кабинета оператора

Источник: [Figma · Т-Страхование](https://www.figma.com/design/s6nhRji3xk5E3It2m9SskY/), экраны 13–18 (`8:217`–`8:222`).

SVG в этой папке сохранены без изменения содержимого и размеров корневого элемента.
Для общей вёрстки Android/iOS/Web они экспортированы в PNG с тройной плотностью и лежат в
`shared/src/commonMain/composeResources/drawable/operator_*.png`.

`operator_photo_door.png` — исходная фотография из макета; `operator_photo_dark.png` — экспорт
отдельного слоя фотографии `19:544` с затемнением. `operator_damage_outline.png` — отдельная
область повреждения `19:655`, которая накладывается на фото в том же месте, что в Figma.
Миниатюры `operator_photo_preview.png` (`19:542`) и `operator_photo_thumbnail.png` (`19:627`)
экспортированы отдельно, чтобы сохранить кадрирование для каждой области интерфейса.
Полные снимки экранов не используются как элементы интерфейса.
